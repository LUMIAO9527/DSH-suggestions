# DSH-Suggestions

为 DeepSeek Harness 提供后续提示词建议和草稿优化。

## 安装

当前本地开发版为 v0.8.3，可在插件管理中从本地目录安装：

```text
D:\Programs\AppLab\DSH-suggestions
```

本地安装包：[`artifacts/dsh-suggestions-0.8.3.tgz`](artifacts/dsh-suggestions-0.8.3.tgz)。

GitHub 已发布版为 v0.7.0：

**Desktop**：在插件管理中从 GitHub 安装，填写：

```text
github:LUMIAO9527/DSH-suggestions#v0.7.0
```

**Web / CLI**：

```sh
dsh plugin --profile web add github:LUMIAO9527/DSH-suggestions#v0.7.0
```

## 使用

| 功能 | 简介 | 按键 |
|---|---|---|
| 显示建议 | 回答完成后，在空输入框中显示一条下一条消息的建议 | 自动出现 |
| 采纳建议 | 把建议填进草稿，可继续编辑后再发送 | `Tab` 或 `→` |
| 关闭建议 | 隐藏当前这条建议 | `Esc` |
| 翻看建议 | 先显示本轮已准备的不同候选，用完后生成其他建议 | `Alt＋↓` 下一条，`Alt＋↑` 上一条；也可点页码两侧的按钮 |
| 主动生成 | 没有显示建议时，根据当前会话生成一条 | 双击 `Tab` 或双击 `→` |
| 草稿优化 | 改写已输入的草稿，保留其中的约束、数字和路径 | 双击 `Tab`，或在文末双击 `→` |
| 选择生成模型 | 在设置页选择建议使用的模型与推理强度 | 见[生成模型](#生成模型) |
| MCP 工具 | 供其他客户端调用建议生成与草稿优化 | 见 [MCP 说明](mcp/README.md) |

没有聊天记录的新会话不生成建议。双击间隔不超过 500 毫秒；草稿上限 16000 字符。每条回答最多保留 10 条候选，发送消息或切换会话后清空；采纳后删空草稿可恢复原候选。主动生成时显示进度；没有合适建议或生成失败时显示结果。

## 按键设置

在 DSH「设置 → DSH-Suggestions」调整快捷键，也可从插件管理器的「DSH-Suggestions → 配置」进入。采纳建议、空框生成、优化草稿、下一条和上一条分别录制。

点击某项的“录制”，按一次或连按两次快捷键，自动识别单击、双击及组合键；录制完成后立即保存并生效，录制时按 `Esc` 取消。

设置采用纯色灰阶、统一圆角按钮和快捷键标签，录制状态以黑白主色显示。输入框内的采纳与翻页按钮沿用同一套视觉样式，支持键盘聚焦。

## 生成模型

在 DSH「设置 → DSH-Suggestions」的「生成模型」中选择建议和草稿优化使用的模型与推理强度。可选模型与输入框右下角的模型选择器来自同一份目录，按提供方分组；选择「自动」时跟随当前会话正在使用的模型。

下拉按提供方分组并勾选当前项；列表较长时提供搜索，支持方向键、`Enter` 选择和 `Esc` 收起。空间不足时向上展开，滚动或点击外部自动收起。模型、推理强度与快捷键的每次改动都会立即保存，保存失败时回退到上一次已保存的值并给出提示。

推理强度选择「自动」时使用该模型公布的最低强度，响应最快。模型与快捷键一起保存在 `~/.dsh/dsh-suggestions-config.json`，旧版快捷键配置仍可直接读取。所选模型或其提供方暂时不可用时，生成会回退到当前会话的模型。

## 超时设置

在 DSH profile 的用户补丁中设置生成超时时间，单位为毫秒：

```yaml
- id: dsh-suggestions
  config:
    timeoutMs: 25000
    noveltyTimeoutMs: 3000
```

`timeoutMs` 控制生成建议的超时，`noveltyTimeoutMs` 控制候选筛选的超时。筛选超时或失败时保留已生成的候选。

## MCP 接入

安装包内的 `mcp/server.mjs` 提供后续提示词建议和草稿优化工具。配置方法见 [MCP 使用说明](mcp/README.md)。
