# DSH-suggestions

为 DeepSeek Harness 提供后续提示词建议和草稿优化。

## 安装

**Desktop**：在插件管理中从 GitHub 安装，填写：

```text
github:LUMIAO9527/DSH-suggestions#v0.6.1
```

**Web / CLI**：

```sh
dsh plugin --profile web add github:LUMIAO9527/DSH-suggestions#v0.6.1
```

## 使用

| 功能 | 简介 | 按键 |
|---|---|---|
| 显示建议 | 回答完成后，在空输入框中显示一条下一条消息的建议 | 自动出现 |
| 采纳建议 | 把建议填进草稿，可继续编辑后再发送 | `Tab` 或 `→` |
| 关闭建议 | 隐藏当前这条建议 | `Esc` |
| 翻看建议 | 浏览当前回答的候选，末尾再往下会请求一条新候选 | `Alt＋↓` 下一条，`Alt＋↑` 上一条；也可点页码两侧的按钮 |
| 主动生成 | 没有显示建议时，根据当前会话生成一条 | 双击 `Tab` 或双击 `→` |
| 草稿优化 | 改写已输入的草稿，保留其中的约束、数字和路径 | 双击 `Tab`，或在文末双击 `→` |
| MCP 工具 | 供其他客户端调用建议生成与草稿优化 | 见 [MCP 说明](mcp/README.md) |

没有聊天记录的新会话不生成建议。双击间隔不超过 500 毫秒；草稿上限 16000 字符。每条回答最多保留 10 条候选，发送消息或切换会话后清空；采纳后删空草稿可恢复原候选。主动生成时显示进度；没有合适建议或生成失败时显示结果。

## 按键设置

在 DSH「设置 → 输入框建议」调整快捷键，也可从「设置 → 插件 → 输入框建议」进入。点“修改”后按下按键或组合键，再点“保存”。翻页组合键按一次执行；自定义单键连按两次执行。设置页可恢复默认按键。

## 超时设置

在 DSH profile 的用户补丁中设置生成超时时间，单位为毫秒：

```yaml
- id: dsh-suggestions
  config:
    timeoutMs: 25000
    noveltyTimeoutMs: 10000
```

`timeoutMs` 管生成建议本身，`noveltyTimeoutMs` 只管生成后那次重复核对。核对超时或失败时会保留已生成的候选，不会让整次生成失败。

## MCP 接入

安装包内的 `mcp/server.mjs` 提供后续提示词建议和草稿优化工具。配置方法见 [MCP 使用说明](mcp/README.md)。
